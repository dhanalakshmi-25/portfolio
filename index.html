Backend-focused Software Engineer with 3+ years building scalable, high-performance systems in fintech and e-commerce. I specialize in microservices architecture, distributed systems, and database performance — turning slow, brittle backends into systems that hold up under real transaction volume.

At Paywize, I work on the backend for a payments platform spanning collections and payouts across UPI, NEFT, RTGS, IMPS, and BBPS, integrated with multiple banking partners through a multi-bank adapter architecture. I designed a database sharding strategy that supported 3x traffic growth with no latency regression, and cut query latency ~40% through indexing, partitioning, and Redis caching.

Earlier, I built backend systems for an e-commerce data platform, travel booking APIs, and a full-stack application delivered for CAIR (DRDO).

What I care about: correctness under load, systems that fail safely, and code the next engineer can actually reason about.
